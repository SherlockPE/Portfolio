# Fabricio López Reyes — Developer Portfolio

Portfolio personal de **Fabricio López Reyes**, graduado de **42 Madrid** y desarrollador de software.

## 🚀 Características

- **Trilingüe**: Soporte nativo para Español, Inglés y Portugués con persistencia en `localStorage`.
- **Modo Oscuro / Claro**: Transición de tema usando la View Transitions API.
- **Hero & Terminal**: Tarjeta interactiva estilo terminal con comandos y métricas reales.
- **Efectos interactivos**: Scramble text al cargar y spotlight con el cursor en el nombre.
- **Proyectos y Hackathons**: Galería con modal lightbox y navegación por teclado (Escape, flechas).
- **Animaciones de scroll**: Revelación suave con `IntersectionObserver` y soporte para `prefers-reduced-motion`.

## 🛠️ Stack Tecnológico

- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Vite**
- **React Icons** (`react-icons/fi`)

## 💻 Desarrollo Local

```bash
# Entrar al directorio
cd Portfolio

# Instalar dependencias
pnpm install

# Servidor de desarrollo
pnpm dev

# Compilar para producción
pnpm build
```
